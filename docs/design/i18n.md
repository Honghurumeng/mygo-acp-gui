# 多语言（i18n）

## 目标

- 界面支持英文（源码语言）和简体中文，默认跟随系统语言。
- 在设置面板切换，立即生效并持久化；`settings.json` 只存一个字符串。
- 不引入第三方 i18n 库：应用自己的文案用 `internal/i18n` 的词典，MyGo 自带的控件/菜单/对话框文案用 MyGo 内置的 `locales/zh-Hans`。
- 翻译缺失时回退到英文原文，绝不显示 key 或空串。
- 非目标：繁体中文、其他语言、RTL、按区域格式化数字/日期、翻译 agent 自己输出或发给 agent 的提示词。

## 两个语言层

| 层 | 内容 | 实现 |
|---|---|---|
| 应用文案 | 侧栏、对话、composer、面板、设置、弹窗、状态和错误提示 | `internal/i18n` + `internal/i18n/zh-Hans.json` |
| MyGo 文案 | 原生菜单、文件对话框、Markdown/代码视图、Undo/Find 等 | `github.com/egoist/mygo/locales/zh-Hans`，由 `mygo.App.SetLocale` 驱动 |

两层用同一个语言值：`internal/ui` 解析出 `en` / `zh-Hans` 后调用 `i18n.Set`，并通过 `Options.OnLanguage` 把设置值交给 `main.go`，后者调用 `mygo.App.SetLocale`（`system` → `SetLocale("")`）。

## 应用文案

英文原文即 key，`internal/i18n/zh-Hans.json` 是 `{英文: 中文}` 的映射，用 `//go:embed` 编进二进制，首次使用时解析一次。

```json
{
  "Settings": "设置",
  "Connecting to %s…": "正在连接 %s…"
}
```

`internal/ui/text.go` 暴露三个薄封装，UI 代码不直接 import `internal/i18n`：

| 函数 | 用途 |
|---|---|
| `T(s)` | 无参数的文案 |
| `Tf(format, args...)` | 带 `fmt` 动词的文案：先翻译再 `Sprintf`，中文翻译必须保留相同的动词顺序 |
| `TS(zh, en)` | 不值得进词典的内联双语（单位、日期布局），如 `TS("1月2日 15:04", "Jan 2 15:04")` |

约定：

- 只在文案最终产生的地方包一层：`m.ui.Text(c, T("Settings"))`、`return Tf("Commit %s · %s", …)`；中间变量保持英文，便于比较和日志。
- 用作内部标识的字符串不翻译：`runGitAction("Commit", …)`、`runFileAction("New file", …)`、`gitNoticeFor(label)`、`T(a.Git.Busy)` 这类“标识 + 展示”共用值，标识保持英文，展示处再 `T(...)`。
- agent 输出、ACP `notice` 文本、`internal/{agent,session,git,files,tasks}` 返回的错误保持英文；`addError` 只对命中的词典文案翻译。
- 任务执行/检查的提示词（`TASK_EXECUTION`、`TASK_COMPLETION_CHECK`）固定英文，不随界面语言变化。
- 按钮的无障碍名（`.Label(...)`）也翻译：测试默认在英文下运行，按英文标签查找不受影响。

## 语言解析

`settings.json` 的 `language` 字段：空值或 `system` 跟随系统，`en` 或 `zh-Hans` 固定；未知值按 `system`。

```json
{ "language": "zh-Hans" }
```

`i18n.Resolve(setting, preferred)`：

1. 非 `system` 时归一化（`zh-CN`、`zh-Hant` → `zh-Hans`；`en-US` → `en`），未知语言回退英文。
2. `system` 时按 `mygo.App.PreferredLanguages()` 的顺序取第一个应用支持的语言；任何 `zh-*` 都映射到 `zh-Hans`（只发行简体），其余回退英文。运行中桌面改了语言（`OnLocaleChanged`）时，`PreferredLanguagesChanged` 重新解析，只有 `system` 且结果真的变了才重画；固定语言不受影响。

`main.go` 启动时先 `app.SetLanguages(i18n.Languages...)`，再让 `appui.New` 读设置并触发第一次 `applyLanguage()`。

## 设置面板

`Settings → Language` 三个单选项：`System`（跟随系统）、`English`、`简体中文`，每个语言用自身文字命名；下方 caption 显示当前生效的语言。切换时：

1. `a.Language = 归一化后的设置值`，`i18n.Set(...)`；
2. `Options.OnLanguage(setting)` → `mygo.App.SetLocale`；
3. `persistSettings()` 写回 `settings.json`。

原生 UI 每帧重建，所以文案立即变化；会话、agent 进程和设置文件不动。已经存成字符串的一次性提示（`Notice`、`TaskError`、`SettingsWarning`）保留生成时的语言，直到被下一次操作替换。

## 覆盖与校验

- `internal/i18n/i18n_test.go` 的 `TestUIStringsAreTranslated` 用 `go/ast` 扫描 `internal/ui/*.go`，要求每个 `T(...)`/`Tf(...)` 字面量在 `zh-Hans.json` 有译文，所以新加的界面文案漏翻译会让 `go test` 失败。
- `TestCatalog` 检查译文非空、`Tf` 动词顺序一致；少数中文直接沿用英文的词（`Agent`、`Diff`）列在 `sameInChinese` 里白名单豁免。
- `TestResolve`/`TestNormalize` 覆盖语言设置解析；`internal/ui/language_test.go` 覆盖系统跟随、面板切换、持久化与重启读回。
- 新增/修改文案后跑 `go test ./internal/i18n`；词典用 `scripts/zh-merge.py` 合并（排序、去重）。

## 已知取舍

- 用英文原文当 key：改写英文文案等于换 key，旧译文会失效并回退英文，需要同步更新词典（测试会提示）。
- 词典是扁平的 `map[string]string`，不支持复数/`select`；本项目没有需要复数的界面文案，需要时用 `Tf` 加条件分支。
- 不翻译时间/数字格式（除少数 `TS` 日期布局）；上下文用量环、耗时等仍用原有格式。
